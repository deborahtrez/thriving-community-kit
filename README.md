# Thriving Community Toolkit 🐍💜

Companion code for **"Building Thriving and Sustainable Dev Communities with Open Source and Python"**
by Deborah Aanyu Oduman, PyLadies.

Four small Python tools that turn "I think our community is doing okay" into
"here's what's working, here's what to fix, and here's the automation that fixes it."

| # | Tool | Question it answers | Runs offline? |
|---|------|---------------------|---------------|
| 1 | `demo1_health_check.py` | Is our open-source project healthy? (new contributors, conversion, response time, bus factor, good-first-issues) | ✅ `--sample` |
| 2 | `demo2_welcome_bot/` | How do we make sure no newcomer opens their first PR into silence? | ✅ `--dry-run` |
| 3 | `demo3_meetup_retention.py` | Are people coming back to our meetups, and did our changes help? | ✅ bundled CSV |
| 4 | `template_welcoming_repo/` | How do I start a project that's newcomer-ready from day one? | ✅ |

## Setup (2 minutes)

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run the demos

```bash
# 1. Health check: sample data, or any public GitHub repo
python demo1_health_check.py --sample
python demo1_health_check.py pyladies/pyladies.com
export GITHUB_TOKEN=ghp_...        # optional: avoids GitHub's 60-requests/hour limit

# 2. Welcome bot: see exactly what a newcomer would see
python demo2_welcome_bot/welcome_bot.py --dry-run demo2_welcome_bot/sample_events/first_pr_opened.json
python demo2_welcome_bot/welcome_bot.py --dry-run demo2_welcome_bot/sample_events/first_pr_merged.json

# 3. Meetup retention: did the buddy system work?
python demo3_meetup_retention.py --change-date 2026-04-18
# ...or with your own export:
python demo3_meetup_retention.py attendance.csv --date-col "Event Date" --id-col "Email" --attended-col "Checked In"

# 4. Scaffold a welcoming repo
cookiecutter template_welcoming_repo
```

Charts and the nudge list land in `output/`.

## Use the welcome bot in your own repo

1. Copy `demo2_welcome_bot/welcome_bot.py` → `.github/scripts/welcome_bot.py`
2. Copy `demo2_welcome_bot/welcome.yml` → `.github/workflows/welcome.yml`
3. Edit `COMMUNITY_NAME` and `CHAT_LINK` in the workflow. Done. GitHub supplies the token.

## About the sample data

Everything in `data/` is **synthetic** (generated by `make_sample_data.py`) so it can be shown
publicly without exposing anyone. Re-generate it any time with `python make_sample_data.py`.
