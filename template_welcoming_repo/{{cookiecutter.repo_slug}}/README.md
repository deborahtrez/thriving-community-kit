## 👋 New here? Start here

1. Read [CONTRIBUTING.md](CONTRIBUTING.md) (5 minutes, promise).
2. Pick an issue labelled [`good first issue`](../../issues?q=is%3Aopen+label%3A%22good+first+issue%22).
3. Comment "I'd like to work on this" and a maintainer will assign it to you.
4. Say hi in our [community chat]({{ cookiecutter.chat_link }}).

You don't need to be an expert, and code isn't the only way to contribute:
docs, design, testing, translation and event help all count.

## Run it locally

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```
