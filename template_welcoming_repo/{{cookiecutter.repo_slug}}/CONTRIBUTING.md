# Contributing to {{ cookiecutter.repo_slug }}

Thank you for being here! First-time contributors are our favourite contributors.

## Your first contribution, step by step

1. **Find an issue** labelled `good first issue` and comment that you'd like it.
2. **Fork** this repository and create a branch: `git checkout -b fix-issue-42`.
3. **Make your change.** Small is beautiful: one issue per pull request.
4. **Test it** before pushing.
5. **Open a pull request** and write `Closes #42` in the description.

A friendly bot will welcome you, and a human maintainer aims to respond within **48 hours**.
If we're slower than that, please nudge us in the [community chat]({{ cookiecutter.chat_link }}). That's not rude, it helps us.

## Other ways to help

- Improve docs or fix typos
- Review someone else's pull request (yes, even as a beginner!)
- Report bugs with clear steps to reproduce
- Translate content
- Help run an event or a study jam

## Getting stuck

Ask! Open a draft pull request early and write what's confusing you.
Questions make the project better for the next person.
