# Governance: how this community stays alive

A community that depends on one person is one burnout away from closing.
These rules exist so that never happens.

## Roles rotate

| Role | Term | Hand-over |
|------|------|-----------|
| Lead organiser | 12 months | Shadow the next lead for one event |
| Issue triager | 3 months | Rotates among maintainers |
| Event host | per event | Anyone who has attended 3+ events can host |

## The contributor ladder

1. **Participant**: attends, asks questions
2. **Contributor**: has one merged PR or has helped run one event
3. **Reviewer**: has 5+ contributions, can approve docs and beginner PRs
4. **Maintainer**: nominated by an existing maintainer, agreed by the others

## Decisions

Small decisions: whoever is doing the work decides.
Big decisions (money, partnerships, changing these rules): discussed in an issue for 7 days, then maintainers agree by consensus.

## Taking a break

Stepping back is healthy. Tell the other maintainers, hand over your open tasks, and come back whenever you're ready.
